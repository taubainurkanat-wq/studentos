# StudentOS — инструкция на русском

## Что уже готово

Это рабочее веб-приложение для студентов. Есть регистрация, вход, демонстрационные данные, задачи, курсы, недельное расписание, приблизительный GPA и база SQLite. Интерфейс на английском.

## Как запустить на Windows

1. Установи **Python 3.11 или новее** с официального сайта python.org. При установке желательно поставить галочку «Add Python to PATH».
2. Распакуй `StudentOS.zip` в обычную папку, например «Документы».
3. Открой папку `StudentOS` и дважды нажми `start.bat`.
4. При первом запуске появится терминал и установятся библиотеки. Для установки нужен интернет.
5. Когда появится адрес `http://127.0.0.1:8000`, открой его в браузере.
6. Нажми **Explore demo workspace**, чтобы посмотреть готовый пример, или **Create an account**, чтобы создать собственный аккаунт.

**Важно:** не закрывай окно терминала, пока используешь StudentOS. Все твои данные сохраняются локально в файле `studentos.db`. Этот файл не нужно загружать на GitHub.

Если двойной клик не работает, открой папку через VS Code, запусти терминал и выполни команды по очереди:

```powershell
py -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m uvicorn app:app --reload
```

## Как работает приложение

- **Dashboard** — главная страница со статистикой и ближайшими дедлайнами.
- **My tasks** — добавление, редактирование, выполнение и удаление заданий.
- **Courses** — предметы, преподаватели, кредиты, текущие оценки и приблизительный GPA.
- **Schedule** — недельное расписание с возможностью добавить лекции и лабораторные.
- **Settings** — изменение имени и выход из аккаунта.
- **Explore demo workspace** — отдельный временный аккаунт с вымышленными данными для демонстрации.

Расчёт GPA примерный: для официального GPA используй правила своего университета.
